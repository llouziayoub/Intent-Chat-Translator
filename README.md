# تطبيق Intent · مترجم المحادثات الفوري (الإصدار 0.6.0.1)

تم بناء هذا التطبيق البرمجي بالكامل استناداً إلى الوثيقة الهندسية والتحليلية لتطبيق **Intent – The Chat Translator (v0.6.0.1)** الصادر في خريف 2026.

التطبيق مطوّر بالكامل باستخدام تقنيات الويب القياسية:
**HTML5 + CSS3 + Modern JavaScript (ES6+)** مع بنية قاعدة بيانات محلية مدمجة **Realm DB Engine**، ومُهيأ بالكامل للتحويل الفوري إلى تطبيق أندرويد بصيغة **APK** (عبر إطار عمل Capacitor / Cordova) وأيضاً للتشغيل على الحواسيب عبر **Electron**.

## 🌟 الميزات الهندسية المطبقة في التطبيق

### 1. المحادثات الفورية ثنائية النص (Bilingual Dual-Bubble System)
- واجهة مراسلة تحاكي نمط المراسلة الفورية المألوف (WhatsApp / Telegram).
- نظام الفقاعات الثنائية المبتكر: النص الأصلي بلون باهت وحجم أصغر، والنص المترجم بخط واضح وبارز وداكن، مع شارة `✓ Translated` ومؤشر زمن الاستجابة العصبي السريع (`< 250ms`).
- دعم تشغيل الرسائل الصوتية مع شريط موجي تفاعلي بصري (`Waveform`) ونبرة صوتية مستنسخة.
- قائمة الضغط المطوّل (`Long-Press Menu`):
  1. عرض النص الأصلي كاملاً.
  2. إعادة توليد الصوت المستنسخ.
  3. تعديل الترجمة يدوياً وحفظها فورياً في Realm DB.
  4. ترجمة الرسالة إلى لغة ثالثة.
  5. حفظ العبارة في دفتر المفردات المخصص.

### 2. وضع المواجهة المباشرة (Face to Face Mode)
- شاشة مقسومة نصفين متناظرين: النصف العلوي مقلوب بزاوية **180 درجة** ليتجه نحو الشخص المقابل الجالس على الطاولة دون الحاجة لتدوير الهاتف.
- أزرار التقاط صوت متوازية متجاوبة بألوان متباينة وتأثيرات نبضية (`Pulse`).
- مؤشر بث موجي تفاعلي ثنائي يرصد شدة الصوت في الزمن الفعلي.
- نطق صوتي فوري ثنائي الاتجاه باللغتين مع تفريغ متزامن.

### 3. التفريغ والترجمة المباشرة للاجتماعات (Live Captions)
- شريط نصوص ثنائي اللغة ينساب في الزمن الحقيقي لمحاكاة اجتماعات Google Meet و Zoom.
- تمييز المتحدثين بأسماء وألوان مستقلة (مثل Amina - Product Lead، Marco - Engineering، Chen - Design).
- مؤشر موجي حي متصل ومؤقت للجلسة مع خيار تصدير محضر الاجتماع بنقرة واحدة.

### 4. معالج استنساخ البصمة الصوتية (Zero-Shot Voice Cloning Wizard)
- معالج من ثلاث خطوات تفاعلية لالتقاط بصمة نبرة صوت المستخدم.
- قراءة عينة نصية طبيعية لمدة 10 ثوانٍ مع مؤقت حلقي تنازلي (`Countdown Ring`).
- مستشعر جودة الصوت ومستوى الضجيج المحيط (`Noise Meter`).
- توليد ومعاينة نبرة الصوت المستنسخة باللغتين الإنجليزية والإسبانية وتخزين الملف التعريفي في Realm DB.

### 5. باقة الأدوات الإنتاجية المساندة (AI Productivity Suite)
- **ترجمة المستندات:** سحب وإفلات ملفات Word و PDF و TXT وترجمتها وتنزيل النسخة المترجمة.
- **مولّد تسميات الفيديو:** تصدير ملفات الترجمة الاحترافية بصيغتي `SRT` و `VTT`.
- **محوّل العملات المباشر:** أسعار صرف لأكثر من 150 عملة عالمية مع حاسبة فورية.
- **دفتر المفردات المخصص:** استعراض الكلمات المحفوظة من المحادثات مع إمكانية الاستماع لنطقها الصوتي.

### 6. نظام الاشتراكات وتنبيهات الاستخدام (Intent Turbo)
- نافذة منبثقة سفلية (`Bottom Sheet`) تعرض استهلاك الكلمات المجانية اليومية (`128 / 500 كلمة`).
- شريط تقدم الاستهلاك ودقائق الصوت، مع خيارات الاشتراك السنوي والشهري وخطط الميزات.

### 7. المكالمات الصوتية والمرئية مع الدبلجة الفورية (VoIP Real-Time Dubbing)
- محاكي مكالمات مع ترجمة صوتية آنية ونصوص تفريغ ثنائية متحركة أسفل الشاشة.

## 🗄️ معمارية قاعدة البيانات المحلية (Realm DB)

يحتوي ملف [js/realm-db.js](file:///c:/Users/ayoub/Desktop/Nueva%20carpeta%20(5)/js/realm-db.js) على تطبيق حقيقي لبنية قاعدة بيانات **Realm DB**:
- **Realm Schemas:** تعريفات هيكلية دقيقة للمخططات (`Chat`, `Message`, `Settings`, `VoiceProfile`, `Vocabulary`).
- **المعاملات الآمنة:** `realm.write(() => { ... })` لضمان تكامل البيانات الذرية.
- **الاستعلامات والنتائج:** `realm.objects(schema).filtered(...).sorted(...)`.
- **المستمعات التفاعلية:** `realm.addListener(...)` لتحديث الواجهات فورياً مع أي تغيير.
- **التخزين الدائم:** تخزين محلي غير متطاير عبر `IndexedDB` مع دعم `localStorage` كبديل تلقائي، مما يجعل التطبيق يعمل بالكامل دون الحاجة لأي خادم خارجي.

## 📱 خطوات بناء تطبيق الأندرويد بصيغة (APK)

تطبيقات الويب (HTML/CSS/JS) يتم تحويلها إلى ملف **APK أندرويد** بنقرة واحدة عبر إطار عمل **Capacitor** (المدعوم رسمياً والمجهز في هذا المشروع):

1. **تثبيت الحزم المطلوبة (مرة واحدة):**
   ```bash
   npm install
   ```

2. **تهيئة منصة الأندرويد:**
   ```bash
   npm run cap:add
   ```

3. **مزامنة ملفات التطبيق (HTML/CSS/JS):**
   ```bash
   npm run cap:sync
   ```

4. **فتح المشروع في Android Studio لتوليد الـ APK:**
   ```bash
   npm run cap:open
   ```
   أو قم بالبناء المباشر بدون فتح الواجهة:
   ```bash
   npm run build:apk
   ```
   ستجد ملف `app-debug.apk` جاهزاً للتثبيت الفوري داخل مجلد:
   `android/app/build/outputs/apk/debug/app-debug.apk`

## 💻 خطوات تشغيل وبناء تطبيق الحواسيب عبر Electron

إذا أردت تشغيل التطبيق كتطبيق سطح مكتب منفصل عبر **Electron**:

1. **تشغيل التطبيق فورياً عبر Electron:**
   ```bash
   npm run start:electron
   ```

2. **تجهيز حزمة التثبيت لسطح المكتب (.exe / .dmg):**
   ```bash
   npm run build:electron
   ```
